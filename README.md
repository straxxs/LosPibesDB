En nuestra empresa Los Pibes nos encargamos de desarrollar y gestionar la base de datos de la farmacia para centralizar toda la info y que el manejo de los datos sea más eficiente. La lógica de negocio se basa en que cada venta impacte directamente en el stock para que el control de los productos sea exacto y en tiempo real. Como política de laburo priorizamos la seguridad y la integridad de la base porque manejamos datos sensibles como recetas y medicamentos; por eso limitamos el acceso a las tablas mediante roles de usuario y realizamos backups automáticos todos los días para garantizar que la información esté siempre disponible y protegida ante cualquier falla técnica.
